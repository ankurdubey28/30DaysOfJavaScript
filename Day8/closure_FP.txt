closures:
1. A closure is the combination of a function bundled together (enclosed) with references to its surrounding state (the lexical environment). 
  In other words, a closure gives a function access to its outer scope. In JavaScript, closures are created every time a function is created, at 
  function creation time.
2. Lexical scoping enables closure in js. Lexical scoping uses notation where a variable is declared
   wihtin source code to determine where that variable will be availabe.
   Eg: function init() {
        var name = "Mozilla"; // name is a local variable created by init
        function displayName() {
        // displayName() is the inner function, that forms a closure
        console.log(name); // use variable declared in the parent function
        }
        displayName();
        }
        init();

Functional Programming

1.Pure functions: those functions which have no side effects and always give same outputs given 
  the same inputs.
2. Goal of pure function is to treat inputs as immutable, and not try to mutate them.
3. Benefits:
   3.1 improved and easy for unit testing.
   3.2 dependent and predictable code.
   3.3 easy to debug and find issues.
   3.4 concurrency safe.
4. Built in pure functions: Math.max(),Math.min(),etc
   Built in impure functions: Math.random(),Date.now()
